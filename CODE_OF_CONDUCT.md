# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. Everyone who takes part (in issues, pull requests, reviews, discussions or any other project space) is expected to follow it.

In short: be welcoming, be kind, assume good intent, accept constructive criticism gracefully, and focus on what is best for the community. Harassment, insults, personal or political attacks, and publishing other people's private information are not acceptable.

## Enforcement

The code of conduct is enforced by the repository owner, [@MITRAKER](https://github.com/MITRAKER).

To report unacceptable behaviour:

- if it happened in a comment, issue or pull request, use GitHub's **Report content** option (the `...` menu on the comment), or
- contact [@MITRAKER](https://github.com/MITRAKER) through GitHub.

All reports will be reviewed and handled promptly and fairly, and the privacy of the person reporting will be respected. The repository owner follows the Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban) when deciding on consequences.
